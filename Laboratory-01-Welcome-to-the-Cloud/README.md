# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux
environment using KillerCoda. I learned how to navigate Linux,
gather system information, organize files, and document my work
using Markdown and GitHub.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed Ubuntu using KillerCoda.
2. Created a new Linux user.
3. Logged in to the new user account.
4. Checked the username, working directory, and hostname.
5. Gathered basic system information.
6. Created directories and Markdown files.
7. Created a GitHub repository.
8. Organized laboratory documentation and screenshots.

I learned basic Linux navigation, user management, system
