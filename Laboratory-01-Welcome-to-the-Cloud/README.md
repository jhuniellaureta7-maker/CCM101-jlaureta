# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity is the first mission in CCM101 – Cloud
Computing. It introduces the basic tools and skills required for
working with cloud infrastructure.

The activity uses KillerCoda to provide a cloud-based Linux
environment and GitHub to create a professional Cloud Computing
Portfolio.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.
- Practice professional documentation.

## Activities Performed

1. Accessed the KillerCoda Linux Playground.
2. Created a new Linux user.
3. Logged in using the newly created account.
4. Checked the username, working directory, and hostname.
5. Gathered Linux system information.
6. Created folders and Markdown files.
7. Created a GitHub repository.
8. Organized the laboratory portfolio.
9. Captured screenshots as evidence.
10. Documented the completed activities.
