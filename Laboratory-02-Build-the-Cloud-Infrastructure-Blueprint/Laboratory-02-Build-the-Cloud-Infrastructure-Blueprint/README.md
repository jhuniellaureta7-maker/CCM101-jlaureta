## Cloud Infrastructure Components

### Compute

Compute resources provide processing power for applications and workloads.

### Storage

Storage resources provide space for saving data, applications, and system files.

### Networking

Networking resources provide communication between systems, applications, users, and the internet.

### Operating System

The operating system manages hardware resources and provides the environment needed to run applications and services.
