## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely recognized for offering a very broad range of cloud services across compute, storage, networking, databases, security, analytics, and other areas. Its large service portfolio allows organizations to build many different types of cloud solutions.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a strong recommendation for an organization that primarily uses Microsoft products. Azure provides strong integration with Microsoft's ecosystem and services, making it easier for organizations already using Microsoft technologies to manage cloud resources.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is widely recognized for its strengths in Artificial Intelligence, Machine Learning, and Kubernetes-related services. Google also has extensive experience with Kubernetes technology and cloud-based AI and ML services.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer equivalent infrastructure categories such as compute, storage, networking, and identity and access management. Although the services have different names and features, they provide similar fundamental building blocks for creating cloud infrastructure.
