## 2. How does Linux support cloud computing?

Linux increases its significance for cloud computing by delivering both stable and flexible OS for servers and applications, as well as many command line utilities, intended for administrators and engineers for inspection, management, and troubleshooting of server resources. During this lab, I managed to utilize Linux commands for operating investigation, including inspecting cloud server OS, CPU, memory, storage, hostname, and network. 

## 3. Why is technical documentation important before deploying infrastructure?

The significance of technical documentation consists in the fact that documentation gives an account of infrastructure configuration, resources used, and design decisions made before the deployment takes place. Well-documented technical documentation informs engineers about the configuration of the environment, makes troubleshooting and maintenance easier.
