# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a major public cloud platform that provides a wide range of cloud computing services. Organizations can use AWS to build, deploy, store, process, and manage applications and IT infrastructure through cloud-based services.

## Global Infrastructure

AWS operates a global infrastructure consisting of geographic Regions and Availability Zones. This infrastructure allows organizations to deploy applications and resources in locations designed to support availability, performance, and scalability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Users can use the console to configure cloud resources, monitor services, and manage their AWS environment.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual computing capacity that can be used to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing and retrieving data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for creating isolated virtual networks and controlling network resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) helps control access to AWS resources by managing identities, permissions, and access policies.

## Three Advantages

1. Wide range of cloud services
2. Global infrastructure
3. Flexible scalability

## Typical Enterprise Use Cases

AWS can be used by enterprises for web applications, data storage, application hosting, backup and disaster recovery, analytics, and other cloud workloads.
