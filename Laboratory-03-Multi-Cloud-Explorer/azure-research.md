# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a public cloud computing platform that provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development.

## Global Infrastructure

Azure provides a global cloud infrastructure organized into regions and availability-related deployment options. This allows organizations to deploy workloads closer to users and design applications for availability and resilience.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources and services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources for running applications and operating systems in the cloud.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for unstructured data such as documents, images, videos, and backups.

### 3. Azure Virtual Network

Azure Virtual Network provides networking capabilities for Azure resources and allows organizations to design private network environments.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management capabilities for users, applications, and resources.

## Three Advantages

1. Strong integration with Microsoft technologies
2. Global cloud infrastructure
3. Broad enterprise cloud capabilities

## Typical Enterprise Use Cases

Azure can be used for enterprise application hosting, Windows workloads, Microsoft 365-related environments, databases, analytics, artificial intelligence, backup, and hybrid cloud deployments.
