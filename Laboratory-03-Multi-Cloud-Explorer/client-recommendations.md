# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a suitable choice for the startup because it provides a broad selection of cloud services that can support a mobile application as it grows. The company can start with resources appropriate for a small workload and scale its infrastructure as the number of users increases. AWS also provides services for computing, storage, databases, and application deployment. This flexibility can help the startup build its application without needing to maintain physical infrastructure.

### Possible Services

* Amazon EC2
* Amazon S3
* Amazon RDS

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most appropriate choice for the university because its existing infrastructure already uses Microsoft technologies. The university uses Windows Server, Microsoft 365, and Active Directory, making Microsoft's cloud ecosystem a natural fit. Azure can support hybrid and cloud migration scenarios while maintaining integration with Microsoft identity and server technologies. This can make the transition easier for the university's existing IT environment.

### Possible Services

* Azure Virtual Machines
* Azure SQL Database
* Microsoft Entra ID

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is a strong choice for the AI research company because the company focuses on Artificial Intelligence and Machine Learning workloads. Google Cloud provides services and infrastructure designed for data processing, AI, machine learning, and high-performance workloads. It also provides technologies that can support modern containerized applications. These capabilities make GCP suitable for an organization whose primary requirement is AI and ML development.

### Possible Services

* Compute Engine
* Vertex AI
* Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a suitable platform for the global e-commerce company because it provides scalable cloud infrastructure for applications serving users in different locations. The company can use cloud services to design highly available systems and automatically scale resources according to demand. AWS also provides services for computing, storage, databases, networking, and application delivery. These capabilities can support an online shopping platform with changing traffic levels.

### Possible Services

* Amazon EC2
* Amazon S3
* Elastic Load Balancing
