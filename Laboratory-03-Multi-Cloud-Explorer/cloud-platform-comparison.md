## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is generally recognized for offering a very broad range of cloud services across computing, storage, databases, networking, security, analytics, and other areas. Its large service portfolio makes it suitable for many different types of workloads.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is the strongest choice for organizations that already depend heavily on Microsoft technologies. Its ecosystem integrates closely with products and services such as Windows Server, Microsoft 365, and Microsoft identity technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes workloads. Its cloud ecosystem includes AI and ML services and Google Kubernetes Engine for managed Kubernetes deployments.

### 4. Which cloud platform would you personally choose and why?

I would choose **[AWS/Azure/GCP]** because it best matches my priorities and the type of workloads I want to develop. I would also consider the available services, pricing, scalability, documentation, and the technologies used by the organization.
