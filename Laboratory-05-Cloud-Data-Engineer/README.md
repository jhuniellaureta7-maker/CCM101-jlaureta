## Mission Overview
This laboratory activity focused on deploying an S3-compatible object storage server using MinIO inside a Docker container. Acting as part of the Cloud Data Engineering Team at CloudNova Technologies, the goal was to build a proof-of-concept object storage environment capable of holding user-uploaded images for a photo-sharing application, since containers themselves are not suitable for long-term data storage.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy an S3-compatible object storage server (MinIO) using Docker
- Access a cloud service via a web interface using port forwarding
- Create a storage bucket and upload objects to it
- Document the cloud storage deployment process using Markdown

## Tools Used
- Docker
- MinIO (quay.io/minio/minio)
- KillerCoda Ubuntu Playground
- GitHub

## Skills Learned
- Deploying a containerized service configured with environment variables
- Exposing and accessing container services through port forwarding
- Creating and managing an object storage bucket via a web console
- Diagnosing and resolving a Docker image pull error
- Writing clear technical documentation in Markdown
