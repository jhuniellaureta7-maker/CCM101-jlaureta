# Security Audit Report

## 1. Principle of Least Privilege (PoLP)
What is it and why is it important for cloud user accounts? 

The Principle of Least Privilege is when a user or an application has only the necessary level of access to fulfill their tasks. It is essential to configure the least privilege to the cloud account to mitigate the risk of an unauthorized attack.

## 2. Attack Surface
What does this term mean when applied to a virtual machine? 

The attack surface of a virtual machine is a set of all possible entry points, to which an attacker can gain unauthorized access. A high attack surface can be represented by open ports, running services, and unnecessary applications.

## 3. Default Deny Policy
Why is it safer to block all traffic by default rather than trying to block specific hackers individually?

The Default Deny policy is a security model in which all activity is disallowed by default and then permitted specifically. The Default Deny is safer compared to the opposite policy, where the provider should constantly monitor and deny requests from attackers. The Default Deny policy allows only the necessary activity for the proper functioning of the cloud services instead of denying everything except the needed one.
