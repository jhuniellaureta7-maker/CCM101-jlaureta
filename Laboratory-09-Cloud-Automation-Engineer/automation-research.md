# Automation Research

## 1. Bash Script

A Bash script is a text file that contains Linux commands arranged to perform tasks automatically. The `#!/bin/bash` line, called the shebang, tells the system to use the Bash interpreter to execute the commands in the file.

## 2. Variables

Variables store values such as folder paths or filenames so they can be reused throughout a script. For example, `$BACKUP_DIR` stores the backup folder's name, making the script easier to update and maintain without repeatedly typing the same path.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts at a specified time or interval. It is essential in cloud operations because it automates repetitive tasks, such as backups, and reduces the chance of human error.
