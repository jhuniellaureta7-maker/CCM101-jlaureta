# Mission Reflection

## 1.  Why is automation critical when managing hundreds of cloud servers? 

Automation is important because managing hundreds of servers manually takes a lot of time and effort. It also helps reduce human errors, especially when doing the same task repeatedly. For example, an automated backup can save important files even when the administrator forgets to do it manually.

## 2. What are the potential dangers of automation? (What happens if there is a destructive typo inside a script that is scheduled to run on 1,000 servers?) 

Automation can be dangerous if the script has mistakes. A wrong command could delete important files or cause problems on many servers at once. That is why scripts should be checked and tested first before using them on actual systems. Automation is helpful, but we must still be careful with the commands we use.

## 3.How did writing a Bash script differ from creating a Docker Compose YAML file (Mission 6)? 

When I created a Bash script, I placed Linux commands in a file so they could run automatically. Docker Compose YAML was different because it was used to define and configure application services. Through this activity, I learned that Bash is useful for automating tasks, while Docker Compose helps manage applications and their services.

## 4.  Review your entire GitHub repository from Laboratory 1 to Laboratory 9. How has your understanding of Cloud Computing transformed over the course of this semester? 

From Laboratory 1 to Laboratory 9, I learned that cloud computing involves more than just creating and running applications. I also experienced working with containers, monitoring resources, securing servers, and automating tasks. These activities helped me understand the importance of keeping cloud systems organized, secure, and efficient.

## 5. Which role did you enjoy the most (Infrastructure Engineer, Cloud-Native Engineer, Security Engineer,etc.) and why?

The role I enjoyed the most was the Cloud Automation Engineer because I learned how to make repetitive tasks easier through scripting.
