## My Final Reflection

Throughout our Cloud Computing laboratory activities, I learned many things about how cloud systems work. From Mission 1 to Mission 9, I became more familiar with Linux commands, cloud infrastructure, Docker, networking, and other tools used in managing cloud environments. Some activities were difficult at first, especially when I encountered commands and configurations that I was not familiar with, but they helped me understand the lessons better through actual practice.

For our final activity, Mission 10, our group created a Nextcloud file-sharing system using Ubuntu Server, Docker Compose, and MariaDB. My assigned task was to handle the application deployment, which included setting up Docker containers, configuring Nextcloud and MariaDB, and making sure that both services were working properly.

One of the challenges in my part was understanding how the two containers communicate with each other. I learned that Nextcloud needs the database to function properly and that the configurations must be correct for the application to run. I also learned how to use Docker Compose to manage multiple containers more easily.

Another important thing I learned was the use of persistent storage. We tested our system by uploading a file to Nextcloud and restarting the Ubuntu Server. After the restart, the file was still there. This helped me understand why persistent volumes are important, especially when managing applications that store user data.

What I enjoyed most about Mission 10 was seeing our application actually work. After setting up the containers, we were able to open Nextcloud in the browser, log in, and upload files. It felt rewarding to see the result of what we worked on as a group.

I also realized how important teamwork and patience are when working on a project like this. Each member had different responsibilities, but we needed to help one another because all the parts of our system were connected.

Overall, Mission 1 to Mission 10 helped me improve my knowledge and confidence in cloud computing. I still have many things to learn, but this subject gave me practical experience in using Linux, Docker, databases, and cloud infrastructure.

This final project taught me that creating a working system is not always easy, but with proper understanding, testing, and teamwork, we can overcome problems and achieve our goals.
